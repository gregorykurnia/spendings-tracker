# C: Tick (the screenshot beside what was read)
- **Idea:** check each line against the bank's own text. The open line shows a crop of the screenshot, highlighted, above the fields. On desktop the whole screenshot sits beside the list.
- **Moving around:** four plain destinations (Check with its count, Spending, All, Categories): a bottom bar on phone, a left rail on desktop. Lines are grouped by screenshot, in the order the bank showed them.
- **Density:** higher but quiet. Ledger rows with aligned columns on desktop, two-line rows on phone. Repeats and incoming money are flagged in place.
- **Type:** Manrope, tabular figures. The screenshot crop uses a plain system sans so source and app read as different things.
- **Colour:** warm sage ground, forest ink, moss for actions, apricot marks the matched line and anything flagged.
- **Name and mark (provisional):** Tick. A white check on a moss square.
